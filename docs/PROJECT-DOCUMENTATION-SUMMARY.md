## 🏗️ Arquitectura Establecida

### Estructura de Tres Capas

```
1. Frontend Estático (Raíz)
   ├── *.html (13 páginas originales)
   └── assets/ (recursos estáticos)

2. Frontend React (src/frontend/)
   ├── Aplicación pública para visitantes
   └── Componentes, páginas, servicios

3. Admin Dashboard (src/admin/)
   ├── Panel de administración React
   └── Gestión de contenido CMS

4. Backend API (api/)
   ├── APIs REST en PHP
   └── Autenticación, CRUD, servicios
```

### Tecnologías Principales

- **Frontend**: React 19.1.0 + Vite + TypeScript
- **Backend**: PHP 7.4+ + MySQL + JWT
- **Admin**: React + TypeScript + Tailwind CSS
- **DevOps**: Docker + GitHub Actions + Scripts automatizados
- **Testing**: Vitest (React) + PHPUnit (PHP)
